# R_M_R_RACE

Игра от **R_M_R**.

Аркадные 3D-гонки на React + TypeScript + Tailwind + Three.js.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
```

**LAN-мультиплеер (2–8 игроков, одна Wi-Fi сеть, без интернета)** — в Desktop-версии для Windows 10/11:
[скачать RMR_Race_Setup.exe](https://github.com/RMR-Amon/R_M_R_RACE/releases/latest/download/RMR_Race_Setup.exe).
На сайте кнопка «Открыть R_M_R Race Desktop» (`rmrrace://lan`) открывает установленное приложение сразу в LAN-мультиплеере.

```bash
npm run desktop     # запустить Desktop-версию из исходников
npm run dist:win    # собрать release/RMR_Race_Setup.exe и RMR_Race_Portable.exe
git tag v1.2.0 && git push origin v1.2.0   # GitHub Actions соберёт и опубликует релиз
```

Архитектура, инструкции, публикация и результаты тестов — [LAN_MULTIPLAYER.md](LAN_MULTIPLAYER.md).

**Управление:** WASD / стрелки — езда, Пробел — использовать предмет, Esc — пауза.
На телефоне и планшете появляются сенсорные кнопки.

## Что внутри
- **Гараж** — 14 машин (9 типов кузова), у каждой свои характеристики и цена в монетах.
- **5 трасс** — Город, Пустыня, Под водой, Пиксельный мир, Мир сладостей.
- **Режимы** — гонка на 1–5 кругов и «Битва» на прямоугольно-круглой арене (очки за попадания).
- **Лаки-блоки** — самонаводящаяся ракета, бомба и масло (одноразовые), нитро, щит, 3 ледяных заряда (заморозка на 1.5 с).
- Ускорители на асфальте, баррикады с тряской экрана, трамплин над обрывом с падением и возрождением.
- Болельщики по теме карты (люди, животные, рыбы, игровые персонажи) с плакатами.
- Награда монетами после каждой гонки, прогресс сохраняется в браузере.

`?debug` в адресе — отладка: в консоли доступен `__game` (`__game.autopilot = true`, `__game.stats`).

## Структура
- `src/game/` — движок: `engine.ts` (физика, ИИ, предметы, камера), `track.ts` (трасса), `trackMesh.ts`, `environment.ts` (декор и болельщики), `carModel.ts`, `particles.ts`, `audio.ts`.
- `src/data/` — машины и карты.
- `src/components/` — экраны интерфейса.
