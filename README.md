# R_M_R_RACE

Игра от **R_M_R**.

Аркадные 3D-гонки на React + TypeScript + Tailwind + Three.js.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
```

**Онлайн-мультиплеер (2–8 игроков из любых городов)** — на сайте https://r-m-r-race.netlify.app: «Мультиплеер» → «Быстрая игра» или закрытая комната по коду. Ничего устанавливать не нужно. Сервер — Cloudflare Workers (Free), устройство и публикация: [ONLINE_MULTIPLAYER.md](ONLINE_MULTIPLAYER.md).

**Отдельно: игра по локальной сети без интернета** (одна Wi-Fi). Сервер запускает только организатор:

```bash
npm install   # один раз
npm start     # проверка, сборка и LAN-сервер; покажет адрес вида http://192.168.x.x:47800
```

Остальные открывают этот адрес в обычном браузере (или сканируют QR-код из игры) и входят в комнату — устанавливать ничего не нужно.
Подробности, порты, брандмауэр, тесты — [LAN_MULTIPLAYER.md](LAN_MULTIPLAYER.md).

**Управление:** WASD / стрелки — езда, Пробел — использовать предмет, Esc — пауза.
На телефоне и планшете появляются сенсорные кнопки: их можно держать сколько угодно одновременно (газ + дрифт + руль + выстрел), палец можно перевести с кнопки на кнопку.

**Во весь экран без рамок браузера:**
- Android, iPad: кнопка ⛶ в меню и в гонке; гонка с телефона сама включает полноэкранный режим.
- iPhone: Safari не умеет скрывать свои панели у сайтов. Поделиться → «На экран "Домой"» — с этой иконки игра открывается во весь экран (кнопка ⛶ показывает эту подсказку).

## Что внутри
- **Гараж** — 14 машин (9 типов кузова), у каждой свои характеристики и цена в монетах.
- **5 трасс** — Город, Пустыня, Под водой, Пиксельный мир, Мир сладостей.
- **Режимы** — гонка на 1–5 кругов и «Битва» на прямоугольно-круглой арене (очки за попадания).
- **Лаки-блоки** — самонаводящаяся ракета, бомба и масло (одноразовые), нитро, щит, 3 ледяных заряда (заморозка на 1.5 с).
- Ускорители на асфальте, баррикады с тряской экрана, трамплин над обрывом с падением и возрождением.
- Болельщики по теме карты (люди, животные, рыбы, игровые персонажи) с плакатами.
- Награда монетами после каждой гонки, прогресс сохраняется в браузере.

`?debug` в адресе — отладка: в консоли доступен `__game` (`__game.autopilot = true`, `__game.stats`).

## Структура
- `src/game/` — движок: `engine.ts` (физика, ИИ, предметы, камера), `track.ts` (трасса), `trackMesh.ts`, `environment.ts` (декор и болельщики), `carModel.ts`, `particles.ts`, `audio.ts`.
- `src/data/` — машины и карты.
- `src/components/` — экраны интерфейса.
- `src/net/` — сетевой код клиента, `cloudflare/` — онлайн-сервер, `server/` — LAN-сервер и общий судья гонки.
